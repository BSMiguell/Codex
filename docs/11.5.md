## Implementação técnica

O `Mapa_Aetheria.html` usa o sistema genérico `CAMADAS` (`data-camada` + boolean). Adicionar novas camadas é trivial:

```js
CAMADAS.política  = { label: 'Política', color: '#5a4a3a', icon: '🏰', active: false };
CAMADAS.mágica = { label: 'Magia', color: '#6a3d9a', icon: '✨', active: false };
```

Não requer alteração estrutural no HTML ou JS — apenas conteúdo (`worldbuilding`) e definição dos objetos.
