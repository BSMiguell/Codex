# §11.9 / §11.10 — Documentação visual e camadas extras do mapa

**Status:** Iniciado (documentação base)  
**Referência:** `docs/checklist-validado.md` (#16 — Mapa camadas extras)  
**Próximos passos:** `§11.5` → `§12`

## Contexto

O `Mapa_Aetheria.html` já possui 3 camadas (`regioes`, `batalhas`, `ceus`) com sistema genérico (`data-camada` + `CAMADAS[nome]`). As camadas extras (`política`, `mágica`, `rotas`, `conflitos`) dependem de worldbuilding (`§11.9` — sistema de magia; `§11.5` — mapa). Este arquivo registra a base visual/documental para expansão futura.

## Estrutura proposta

```text
Mapa_Aetheria.html
  CAMADAS (3 existentes)
  + CAMADAS.política → dados de facções/reinos (derivado de battles.lados)
  + CAMADAS.mágica → sistema de magia (§11.9)
  + CAMADAS.rotas → caminhos entre regiões
  + CAMADAS.conflitos → batalhas detalhadas
```

## Dependências

- `§11.9` — Worldbuilding: magia com regras e custos (`docs/checklist-validado.md` #11)
- `§11.5` — Camadas extras do mapa (adiado para Q1/2027 — conteúdo novo)
- `historia-api.json` — `battles[5]`, `regions[16]`, `celes[5]`

## Próximo passo operacional

Atualizar `docs/11.9_11.10.md` quando `§11.9` (sistema de magia) estiver definido; o código do mapa já suporta a adição de chips (`data-camada`) sem alteração estrutural.
